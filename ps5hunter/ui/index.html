完整設定

1

登入 Facebook

按下面的按鈕會開啟一個 Chrome 視窗，請在裡面登入要跑監控的帳號。登入成功後這個視窗會自動關閉。

2

要監控的社團

抓取後會列出目前 Facebook 帳號已加入的社團，預設全部不勾選，請自行勾選要監控的社團；勾選結果會與下方「各社團套用哪些規則」即時同步。

按上面按鈕抓取，或直接在下面貼社團網址。
3

監控物品與價格條件

⚡ 商品規則一鍵範本庫
還沒有物品，按下面的「＋ 新增物品」或從上方範本庫一鍵套用。

支援不分大小寫部分比對；也可直接從封面「最近命中紀錄」點「封鎖賣家」，或用手機遠端指令 /block 賣家名 加入。

這些欄位怎麼用？（點開看說明）
關鍵字：產品名稱，任何一個出現就會進入判斷（純英文自動詞界比對）。
必須包含：產品的類型／規格字，必須出現在主體區（不含相容性說明與 #hashtag）。
全域排除詞：整篇出現就跳過，適合放「故障機、空盒、不要的子型號（如 PS5 Pro）、已售出」；內建否定保護，不會誤殺「售出不退」或「收納包」。
主體／配件排除詞：只有當「賣的主體本身」是這些配件時才排除，若主商品「附贈手把／遊戲片」不會誤殺！
忽略型號數字：列出該品類常見的型號／容量數字（如 1218、2018、2118），防止裸數字被誤當成價格。
價格需靠近產品字：針對非結構化段落，價格與產品字的距離上限（字數）；斜線對應、欄位對應與商品卡會自動精準綁定。
最低／最高價：只針對「已綁定目標商品」的實際售價判定，不會再把多品項貼文裡的便宜配件價誤當成主機價。
測試方式：把一篇貼文貼到下面的「規則測試器」，它會告訴你是哪一關擋掉的。

Email 通知

機器人信箱（寄件者）

登入機器人 Google → 開啟兩步驟驗證 → 建立應用程式密碼（選「其他」）→ 貼回這裡。程式不會代替你登入 Google。

寄件者使用程式內建的機器人信箱，你不需要填應用程式密碼。

4

通知渠道（Discord／Telegram／Email）

可複選；Email 以外需要先設定憑證。所有憑證均以 Windows DPAPI 本機加密儲存。

Discord（推薦：手機秒彈推播、帶商品第一張實拍縮圖與直達連結）

在 Discord 私人頻道點「編輯頻道 → 整合 → Webhook → 新 Webhook → 複製網址」貼上即可；可單獨勾選 Discord，免設 Gmail。

進階：Discord 雙向遠端指令設定（選填，改預算／暫停／封鎖賣家用）

在 Discord Developer Portal 建立 Bot 並開啟 Message Content Intent 邀請進私人頻道即可用 /status、/price 等指令遠端控制。

Telegram（推播＋內建支援遠端指令）
