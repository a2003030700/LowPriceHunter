設定

1

登入 Facebook

按下面的按鈕會開啟一個 Chrome 視窗，請在裡面登入要跑監控的帳號。登入成功後這個視窗會自動關閉。

2

要監控的社團

抓取後會用目前 Facebook 帳號的社團取代清單；切換帳號後請重新抓取。

只會自動勾選「名稱符合規則關鍵字」的社團（例如規則含 PS5），其餘預設不勾選。

按上面按鈕抓取，或直接在下面貼社團網址。
3

監控物品與價格條件

還沒有物品，按下面的「＋ 新增物品」開始。
這些欄位怎麼用？（點開看說明）
關鍵字：產品名稱，任何一個出現就會進入判斷。
必須包含：產品的類型字，至少要出現一個；用來避免「平台／分類字」被當成商品。
排除詞：出現就跳過，例如「遊戲片、手把、徵求、已售」。
價格需靠近產品字：價格與產品字的距離上限（字數），越小越嚴格。
排除多項商品清單：貼文有 3 個以上價格、又沒有合售字時，視為商品清單跳過。
合售／整組等字：出現這些字就允許一篇貼文列多個價格。
最低／最高價：合理價格範圍，範圍外的價格不列入判斷。
測試方式：把一篇貼文貼到下面的「規則測試器」，它會告訴你是哪一關擋掉的。
3

各社團套用哪些規則

勾選每個社團要套用的物品。全部不勾＝這個社團不監控。

先在上面選社團、新增規則。
3

規則測試器

貼一段貼文，看看每條規則會不會命中、卡在哪一步（不會送出、不會寄信）。

（尚未測試）
4

Email 通知

機器人信箱（寄件者）

登入機器人 Google → 開啟兩步驟驗證 → 建立應用程式密碼（選「其他」）→ 貼回這裡。程式不會代替你登入 Google。

會逐一寄送，收件者不會看到彼此的信箱；最多 20 個。

寄件者使用程式內建的機器人信箱，你不需要填應用程式密碼。

4

通知渠道

可複選；Email 以外需要先設定憑證。憑證會用 Windows DPAPI 加密。
